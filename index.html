LIV Reel Publisher
Privacy Policy

Last updated: 7 November 2026

LIV Reel Publisher is an internal tool operated by Christian Robertson for the LIV / Neo Productions Facebook Page. It prepares and publishes LIV music reels to the authorised Page. It is not a public sign-up service.

Information used

The connection to Meta uses the authorised administrator's account information during authorisation, the selected Page's name and identifier, and an access token. The publisher stores the Page identifier and access token privately on the operator's server. It processes music, artwork, video files, titles and captions supplied by the operator.

The publisher also keeps local posting records, including song titles, file fingerprints, processing states, timestamps and Facebook video identifiers and links. These records help prevent duplicate uploads and resolve interrupted publishing attempts. It does not intentionally collect followers' profiles, private messages, comments or contact lists.

Purpose and access

This information is used to authenticate the Page connection, publish authorised content, check publication status and maintain the publishing service. Meta permissions requested for this integration are pages_show_list, pages_read_engagement and pages_manage_posts. The connection is restricted to the Page selected by the administrator.

Sharing and security

Video content, titles, captions and the necessary authentication information are transmitted to Meta to provide the publishing service. Published reels and captions are intended to be public on Facebook. Access tokens are stored in a restricted server directory and are not included in this public website or its repository. App data is not sold or used for advertising profiles.

Meta processes information under its own Privacy Policy. This policy page is hosted by GitHub Pages; GitHub may process technical request information, such as IP addresses, under its Privacy Statement. This page contains no added analytics, advertising trackers or submission forms.

Retention

The Page credential is retained while the integration is in use, unless revoked or removed. Local publication records are retained while needed to operate the service and avoid duplicates. Media files are retained in the operator's music library. Removing the app connection does not automatically remove local records, source media or previously published Facebook posts.

Data deletion and disconnecting

The administrator can revoke LIV Reel Publisher through Facebook's app or business integration settings. To request removal of information held by the publisher, or to ask a privacy question, contact Christian Robertson through the LIV / Neo Productions Facebook Page, identifying “LIV Reel Publisher” and the Page or record concerned. Please do not send passwords or access tokens.

Requests can include access, correction or deletion of information associated with the integration. We may need to confirm that the requester is authorised to manage the Page. Previously published content must also be removed from Facebook if its deletion is requested; revoking access alone does not delete posts. Meta and GitHub manage information they hold under their own policies.

YouTube publishing

LIV YouTube Publisher is the YouTube connection for the same internal publishing service. With the channel owner's permission it uses the YouTube API Services to upload LIV videos, read the channel's upload list and check processing and visibility. It stores the selected channel ID, OAuth client credentials and refresh token in a restricted directory on the operator's server. Video IDs, titles, publication states and file fingerprints are retained to avoid duplicate posts.

Video files, titles, descriptions, audience and synthetic-content declarations are sent to YouTube. Public videos are intended to be visible on YouTube. Credentials are sent only to Google's authentication and API endpoints. Google data is not sold, used for advertising profiles or used to train AI models. Google processes information under its Privacy Policy; YouTube use is subject to the YouTube Terms of Service.

The owner can revoke access through Google Account connections. Contact Christian Robertson through the LIV Facebook Page above to request deletion of locally stored YouTube connection data and posting records. Revoking access does not delete existing YouTube videos; those can be removed in YouTube Studio. Media files remain in the operator's own library until removed by the operator.

Changes

Changes to this tool's data practices will be reflected on this page with an updated date.
